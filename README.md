# AI/ML Engineering-Project

This directory showcases my expertise in building predictive models and deep learning architectures. From classical regression to advanced Seq2Seq neural networks, these projects demonstrate my ability to engineer robust AI solutions.

## Project Index

### 1. Deep Seq2Seq Cryptocurrency Forecasting
> **Advanced Time-Series Modeling**

* **Objective**: To predict Bitcoin price volatility using custom deep learning architectures.
* **Innovation**: Implemented a **Seq2Seq LSTM Encoder-Decoder** with custom training loops (`tf.GradientTape`), achieving a baseline MAE of 0.0100.
* **Tech Stack**: TensorFlow, Keras, Time-Series Analysis.
* **🔗 Repository**: [Link to Deep Seq2Seq](https://github.com/adolesans/AI.ML-Engineering-Project/tree/main/Deep-Seq2Seq-Crypto-Forecasting)

### 2. Hybrid Neural Recommendation Engine
> **Recommender Systems (RecSys)**

* **Objective**: To solve the "cold-start" problem in content discovery.
* **Innovation**: Architected a dual-tower system combining **Neural Collaborative Filtering (NCF)** for user behavior and **TF-IDF** for content similarity.
* **Tech Stack**: TensorFlow, Scikit-Learn, NLP.
* **🔗 Repository**: [Link to Hybrid RecSys](https://github.com/adolesans/AI.ML-Engineering-Project/tree/main/Hybrid-Neural-Recommendation-Engine)

### 3. AutoWorth Predictor
> **Predictive Analytics & Regression**

* **Objective**: To estimate used car market values with high precision for business valuation.
* **Innovation**: Applied advanced Feature Engineering and Regression techniques to maximize R-squared scores on real-world automotive data.
* **Tech Stack**: Scikit-Learn, Pandas, Regression Analysis.
* **🔗 Repository**: [Link to AutoWorth](https://github.com/adolesans/AI.ML-Engineering-Project/tree/main/AutoWorth-Predictor)

### 4. CekManis: Diabetic Risk Classification
> **Collaborative Project** | *Contribution: ML Engineer & Code Reviewer*

* **Objective**: Optimized the end-to-end Machine Learning pipeline by implementing robust Feature Selection and handling class imbalance, resulting in a highly generalizable model with reduced overfitting. To develop a classification model for early detection of health risks (Diabetes/Sugar analysis). 
* **Key Contribution**: Collaborated on data preprocessing and model selection to ensure high sensitivity and specificity in medical predictions.
